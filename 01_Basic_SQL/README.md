# Basic SQL

## Overview

This section covers the foundational SQL concepts that form the building blocks of database querying and analysis. The exercises focus on retrieving data from tables, selecting specific columns, sorting results, and understanding the structure of relational databases.

## Topics Covered

- SELECT statements
- DISTINCT
- ORDER BY
- TOP
- Column Aliases
- Basic Data Exploration

## Objectives

By completing these exercises, I developed the ability to retrieve and inspect data efficiently, understand table structures, and write clean SQL queries that serve as the foundation for more advanced analytical techniques.

## Skills Demonstrated

- Data retrieval
- Query construction
- Result set manipulation
- SQL syntax fundamentals
